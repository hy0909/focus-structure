# 로그인 카드 너비와 12단 그리드

작성: hy0909

로그인 카드는 12단 그리드의 가운데 4칸(5~8번째 칸) 너비를 따른다. 화면이 넓어지면 카드도 같이 넓어지고, 500px에서 멈춘다.

## 그리드

| 항목 | 값 |
|---|---|
| 칸 수 | 12 |
| 칸 사이 간격 | 20px |
| 화면 좌우 바깥 여백 | 각 20px |
| 칸 너비 | (화면 너비 − 260px) ÷ 12 |

260px는 바깥 여백 40px(20 × 2)과 칸 사이 간격 220px(20 × 11)를 더한 값이다. 칸 너비는 고정값이 아니고 화면 너비에 따라 늘어난다.

## 카드 너비

카드 너비는 4칸과 그 사이 간격 3개를 더한 값이다.

```
카드 너비 = 칸 너비 × 4 + 20px × 3
         = (화면 너비 − 260px) ÷ 3 + 60px
```

| 화면 너비 | 4칸 계산값 | 실제 카드 너비 | 비고 |
|---|---|---|---|
| 1280 미만 | 400 미만 | 400px | 최소 400 유지 |
| 1280 | 400 | 400px | 5~8번째 칸에 딱 맞음 (x 440~840) |
| 1440 | 453.3 | 453.3px | 그리드에 맞춰 늘어남 |
| 1580 | 500 | 500px | 최대 너비 도달 |
| 1920 | 613.3 | 500px | 최대 500에서 멈춤 |

정리하면 규칙은 세 가지다.

1. 최소 너비는 400px이다. 1280보다 좁은 화면에서도 400px을 유지한다.
2. 1280~1580 구간에서는 그리드 4칸 너비를 그대로 따른다.
3. 최대 너비는 500px이다. 1580을 넘으면 더 늘어나지 않고 가운데 정렬만 유지한다. 이 구간에서는 카드 양 끝이 그리드 선과 맞지 않는다.

화면이 400px보다 좁은 모바일에서는 화면 너비에 맞춘다. 이때 화면 좌우에 16px 여백을 둔다.

## CSS 예시

```css
.card {
  width: max(calc((100vw - 260px) / 3 + 60px), min(400px, 100%));
  max-width: min(500px, 100%);
}
```

`max(..., min(400px, 100%))`가 최소 400px을 지키고, 공간이 400px보다 좁으면 100%로 줄인다. `max-width: min(500px, 100%)`가 최대 500px을 지키면서 화면 밖으로 넘치지 않게 막는다.

## 카드 안쪽 여백

| 위치 | 데스크톱 | 화면 460px 이하 |
|---|---|---|
| 입력 영역 좌우 | 56px | 24px |
| 하단 영역 (위 / 좌우 / 아래) | 24 / 56 / 48px | 24 / 24 / 48px |

## 화면 크기 규칙(스케일)과의 관계

카드 너비는 스케일 규칙과 상관없이 위 공식만 따른다. 스케일 규칙을 켜면 카드 안의 글자, 입력창, 버튼 크기만 커지고 카드 너비는 그대로다.

## 확인 방법

시안 페이지 오른쪽 위 도구에서 「12단 그리드 보기」를 누르면 빨간 칸이 겹쳐 보인다. 1280 화면에서 카드 양 끝이 5번째 칸 왼쪽 선과 8번째 칸 오른쪽 선에 맞으면 정상이다.
